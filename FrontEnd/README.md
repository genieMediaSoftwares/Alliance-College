# Alliance College of Hotel Management Website

A modern, responsive, and professional educational website developed for **Alliance College of Hotel Management** using **React + Vite** with **Tailwind CSS** for styling.

The website showcases courses, placements, campus life, gallery, blogs, contact information, and other college-related content in a visually engaging and user-friendly manner.

---

## 🚀 Project Overview

This project was developed according to the client’s requirements to create a professional digital presence for the college.

The website includes:

* Responsive modern UI/UX
* Course showcase pages
* Placement highlights
* Campus & gallery sections
* Blogs & updates
* Contact & enquiry forms
* Professional hero sections
* Interactive animations & components
* Mobile-friendly layouts
* Optimized performance using Vite

## 📦 Installation & Setup

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to project folder:

```bash
cd alliance-college-website
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
